# some-skills
## ideas
+ 自动生成Commit Message，提交到远端
+ 写一个美化返回值的skill（比如json结构），背景是每次服务端下线字段时都需要跟前端二次确认下，能够根据注释自动生成一个好的结构给前端看，最好是生成一个文件能够让前端点击确认
+ 用别人的音色唱某首歌的高潮部分，比如我喜欢的歌曲《被生命所厌恶》，这首歌的男声非常好听，是否可以唱毛不易的《像我这样的人》，并且转成日语翻唱
+ skills模版生成，目前每写一个skills，都需要手动创建一些文件夹，比如SKILL.md，scripts等。这样有些低效，并且有些想法不够完善，可以让ai生成对应的文件，初始化一个模版，之后自己完善并且修改
+ 用户输入一个商品，自动在多个平台比价，生成一个表格给用户对比，将链接给用户，点击之后跳转到对应app。或者直接帮用户下单，背景是：我想要买宠物雨衣，在群里问，大家只给了一个商品名字，我还需要去各个平台搜索下
+ 目前遇到的一个问题是，我想要将旧手机的照片，关于人物，时间，地点，包含狗狗的照片导出 ，背景是：旧手机上有很多出去玩的照片，我想要将一些有标志性的照片找出来，当作timeline用，但是人工找比较麻烦
+ 如果有两张差不多的图片 或者视频 如何区分哪张更好？如果是同一个人物，同一个第天，但是是两个风格（比如白天和晚上），哪个更好？
+ 根据一个视频风格，将里面的人物替换，生成一个新的视频，或者根据已有的创意，生成相同的创意【【男巫ZachKing】2026最佳魔术！】 https://www.bilibili.com/video/BV1BuHC6rEuX/?share_source=copy_web&vd_source=2cf8cc3ae63eee56456594b4bb6cc7e3
+ 提取视频中的全量文字，并生成总结，需要去思考：如果视频内容很长怎么办
+ 需求分支合并到develop分支时，存在冲突，解决冲突的事情能否交给AI去做？
+ 人宠写真照，目前人们养宠的越来越多，给一个人和宠物的照片，生成一张高清图片
